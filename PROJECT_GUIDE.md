# Organic Chicken Hub - Project Guide

Welcome to the **Organic Chicken Hub**! This document is designed to help AI tools, IDEs, and developers understand the project's mission, architecture, and development workflows.

---

## 🎯 Project Mission
Organic Chicken Hub is a SaaS platform dedicated to aggregating and comparing organic chicken prices from various vendors in Bangladesh. It provides transparency, price history, and vendor reviews to help consumers make informed decisions.

---

## 🛠️ Tech Stack
- **Framework**: [Next.js 15+](https://nextjs.org) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org)
- **ORM**: [Drizzle ORM](https://orm.drizzle.team)
- **Database**: PostgreSQL (via `postgres.js`)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **UI Components**: Radix UI + Lucide React
- **Data Fetching**: Firecrawl (for scraping vendor data)
- **Validation**: Zod

---

## 📂 Directory Structure
- `src/app/`: Next.js App Router routes, layouts, and API endpoints.
    - `api/scrape/`: Contains logic for triggering and handling scraping tasks.
    - `admin/`: Dashboard for managing products and scraping configurations.
- `src/components/`: Reusable UI components (buttons, cards, navigation, etc.).
- `src/db/`: Database schema definitions (`schema.ts`) and connection logic.
- `src/lib/`: Utility functions, constants, and shared logic.
- `src/data/`: Static data sources (e.g., blog contents).
- `src/scripts/`: Maintenance scripts (e.g., database seeding).
- `drizzle/`: SQL migrations generated by Drizzle Kit.

---

## 💾 Data Model
The database consists of the following key tables:
- **`products`**: Stores details of organic chicken products (names, prices, vendors, URLs).
- **`price_history`**: Tracks price fluctuations over time for each product.
- **`reviews`**: Contains user or aggregated reviews for vendors.
- **`scraping_configs`**: Stores URLs and activation status for vendor scraping tasks.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v20+)
- PostgreSQL instance

### 2. Environment Setup
Copy `.env.example` (if present) or create a `.env` file with:
```env
DATABASE_URL=postgres://user:password@localhost:5432/organic_chicken
FIRECRAWL_API_KEY=your_key_here
```

### 3. Installation & Development
```bash
npm install
npm run dev
```

## 🤖 AI & Developer Guidance

### How to...
- **Add a Route**: Create a new folder in `src/app/` with a `page.tsx`.
- **Modify Schema**: Edit `src/db/schema.ts`, then run `npx drizzle-kit push` (or generate a migration).
- **Add a Component**: Create a new file in `src/components/` and use Tailwind CSS v4 for styling.
- **Implement a Scraper**: Use the Firecrawl client in `src/app/api/scrape/` to extract data from vendor websites.

### Coding Standards
- Use **functional components** and **React Server Components** (RSC) by default.
- Use **Tailwind CSS** for all styling; avoid inline styles or CSS modules unless necessary.
- Ensure **TypeScript** types are strictly defined.
- Follow **Lucide React** patterns for icons.
